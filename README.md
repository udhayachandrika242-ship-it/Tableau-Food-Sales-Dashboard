# Food Sales Dashboard using Tableau

## Project Overview
This project analyzes food sales data using Tableau to understand sales performance and product category trends.

## Tools Used
- Tableau
- Excel (for dataset preparation, if applicable)

## Work Done
- Imported the food sales dataset into Tableau.
- Explored the available fields in the dataset.
- Created a Total Sales visualization using the Total Amount field.
- Analyzed food sales using category-wise visualizations.
- Explored quantity and other available sales details.
- Used filters to explore different food categories.
- Created visualizations to present food sales information clearly.

## Objective
The objective of this project is to analyze food sales data and understand sales performance across different food categories.

## Outcome
The dashboard helps users explore food sales information and understand category-wise sales patterns through visualizations.
